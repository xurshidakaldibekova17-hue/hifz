# Ҳифз — Қуръон ёдлаш иловаси

Телефон ва компьютерда ишлайдиган веб-илова (PWA). Интернетсиз ҳам ишлайди (аудио ва микрофон учун интернет керак).

## Ишга тушириш
1. `start.bat` файлини икки марта босинг (Node.js ўрнатилган бўлиши керак). Браузерда http://localhost:5173 очилади.
2. Телефонда ишлатиш учун папкани GitHub Pages, Netlify ёки истаган хостингга жойланг, сўнг телефон браузерида очиб «Бош экранга қўшиш» қилинг.
3. Микрофон орқали текшириш фақат Chrome / Edge да ишлайди.

## Бўлимлар
- **Бош** — бугунги вазифа, такрор, кетма-кет кунлар.
- **Режа** — бутун Қуръон / жузлар / суралар, неча кунда (стандарт 30 кун). Илова кунларга тенг тақсимлайди.
- **Ёдлаш** — ҳар оят 5 босқич: тинглаш → ярим ёпиш → тўлиқ ёпиш → тартиблаш → текшириш (90%+ бўлсагина «ёдланган»).
- **Такрор** — 1, 3, 7, 14, 30, 60, 120, 240 кун оралиқли такрорлаш.
- **Машқ** — зеҳн (тушган сўз, кейинги оят, қайси сура, жуфт топиш, сўз занжири, рақам хотираси) ва кўз (Шульте, чақмоқ сўз, пейсер, кўз гимнастикаси).
- **Текшириш** — микрофон орқали сўз хатолари (лаҳн жалий) + Айман Сувайд услубидаги тажвид рўйхати (лаҳн хафий).
- **Қуръон** — 114 сура, тажвид рангли матн, Муҳаммад Содиқ таржимаси, аудио.

## Маълумот манбаи
`data/` даги JSON файллар api.alquran.cloud дан олинган (quran-tajweed, uz.sodik). `node build-data.js` билан `js/quran-data.js` қайта тузилади.
